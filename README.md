KISHORE J — PORTFOLIO WEBSITE

This repository contains a responsive, single-page portfolio for a PHP and Laravel developer.

Files
- index.html: portfolio website (GitHub Pages entry point)
- Kishore_J_Resume.pdf: downloadable resume

Publishing with GitHub Pages
1. Open Settings → Pages in this repository.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder / (root), then Save.
4. After deployment completes, visit https://laravel21.github.io/kishore-portfolio/.

The site uses plain HTML, CSS and JavaScript; no build step is required.
